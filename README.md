# IPTV Rot-Weiss

IPTV-App für Android (Xtream-Codes-Zugang) im rot-weißen Look – für FC-Fans.

- **FC-Zentrale:** nächstes Spiel mit Countdown, letztes Ergebnis, Spielplan, Tabelle (Daten: OpenLigaDB)
- **Spieltag-Modus:** am Spieltag Schnellstart der ausgewählten FC-Sender, Live-Spielstand
- **Live-TV:** Kategorien, Suche, Jetzt/Danach, Programm (EPG), Catch-up
- **Filme & Serien:** Poster, Suche, Sortierung, Fortsetzen, automatisch nächste Folge
- **Meine:** Weiterschauen und Favoriten
- **Kindersperre** und **Bild-in-Bild** (Handy)
- **Fire TV / Android TV:** Bedienung nur mit der Fernbedienung, Seitenleiste, große Oberfläche, im Player ▲▼ Sender wechseln, ◀▶ spulen, OK Pause/Info

## APK

Bei jedem Push auf `main` baut GitHub die App. Die fertige **IPTV-Rot-Weiss.apk** liegt unter **Releases → Neueste Version**.

Hinweis: Dies ist ein privates Fan-Projekt ohne Verbindung zum 1. FC Köln.
